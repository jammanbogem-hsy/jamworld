# Jamworld / 모아 월드

ZEP에서 참고한 공간·맵 제작 흐름에, 선명한 만화체의 탑뷰·아이소메트릭 에셋과 자연어 맵 편집을 결합하는 교육용 웹앱입니다.

## 현재 상태

검증된 v2 기준 소스와 원본 에셋을 보관합니다. 포털 연결 안내, 배치 크기 조절, 맵 페이지, 학생 에셋 공방과 교사 승인 기능은 개발 중이며 이 기준 버전에는 아직 포함되지 않습니다. 변경은 검증된 기능 단위로 커밋합니다.

- `app/`: React + Vinext 웹앱, Canvas2D 렌더러, 맵 편집·플레이·에이전트 API
- `design/assets/`: 직접 생성한 PNG 원본, 두 시점의 시트, 프레임 좌표, 생성 프롬프트
- `app/public/assets/atlas/`: 실행에 사용하는 압축 WebP와 프레임 JSON
- `design/ASSETS.md`, `design/DUAL_VIEW_V2.md`: 에셋 출처와 카메라·스타일 규격

## 로컬 실행

Node.js 22.13 이상을 사용합니다.

```sh
cd app
npm ci
npm run dev
```

에이전트 API를 쓰려면 `app/.dev.vars`에 `OPENAI_API_KEY`와 `ANTHROPIC_API_KEY`를 로컬로 설정합니다. 키가 없는 기능은 사용할 수 없으며 키 값은 저장소에 포함하지 않습니다. 세부 빌드·DB 명령은 `app/README.md`에 있습니다.

## 기존 프로젝트로 가져가기

가장 먼저 전체 앱을 별도 경로 또는 서브도메인에서 실행해 연결할 수 있습니다. 화면을 직접 합치려면 기존 프로젝트의 프레임워크·로그인·서버 구조에 맞춰 라우트와 API를 통합해야 합니다. 포크만으로 다른 앱에 자동 삽입되지는 않습니다.

에셋만 가져가려면 `app/public/assets/atlas/`, 카탈로그(`app/lib/world/catalog.ts`), 프레임·렌더 규격을 함께 옮깁니다. 원본 수정과 재패킹까지 하려면 `design/assets/`와 `app/scripts/build-atlas.mjs`도 보존합니다. 이미지 파일만 옮기면 충돌 크기, 바닥 기준점, 방향·시점 정보는 자동으로 따라가지 않습니다.

현재 맵은 브라우저에 저장됩니다. 실제 사용자가 만든 맵은 편집기의 내보내기를 사용해야 하며 Git 포크에는 포함되지 않습니다. 향후 서버의 사용자·승인·생성 에셋 데이터와 파일 저장소도 소스와 별도로 내보내기·이관해야 합니다.

`app/.openai/hosting.json`의 `project_id`는 현재 운영 Site를 가리킵니다. 독립적으로 배포하는 포크에서는 해당 ID를 재사용하지 말고 새 호스팅 프로젝트를 연결해야 합니다. API 키와 호스팅 설정도 새 환경에 별도로 설정합니다.

## 에셋 출처

이 저장소의 모아 월드 그림은 이미지 생성 도구로 새로 제작한 에셋입니다. 브롤스타즈 APK에서 추출한 그림·캐릭터·로고는 런타임에 포함하지 않았습니다. 스타일과 데이터 구조를 분석한 참고용 APK 및 추출 분석 자료는 이 공개 저장소에 포함하지 않습니다. 제3자 라이브러리와 제공된 빌드 도구의 라이선스 고지는 원본 파일에 유지합니다.

학생이 나중에 만든 그림·생성 결과는 개인/학급 저장소에 보관하며, 공개 Git 저장소에 자동 업로드하지 않습니다.
