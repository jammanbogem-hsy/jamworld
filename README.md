# Jamworld / 모아 월드

ZEP에서 참고한 공간·맵 제작 흐름에, 선명한 만화체의 탑뷰·아이소메트릭 에셋과 자연어 맵 편집을 결합하는 교육용 웹앱입니다.

## 현재 상태

포털 연결 안내, 배치 크기 조절, 맵 페이지, 아이소 8방향 이동, 학생 에셋 공방과 교사 승인 기능을 포함한 소스와 원본 에셋을 보관합니다.

운영 사이트: https://moa-world-studio.jhet8993.chatgpt.site

- 시작 포털을 표시한 상태에서 같은 페이지 또는 다른 페이지의 도착 위치를 선택합니다.
- 페이지 추가·이름 변경·복제·순서 변경과 페이지 간 포털을 지원합니다. 포털 쌍은 함께 실행 취소/복구합니다.
- 배치 오브젝트의 크기를 0.5~3배로 조절합니다. 점유 칸을 올림 처리하여 그림보다 작은 충돌 영역이 생기지 않게 합니다. 안내판·퀴즈·포털은 1배 고정입니다.
- 아이소 이동은 화면 방향별 속도를 맞추고 8방향 그림과 실제 이동 거리 기반 걷기 동작을 사용합니다.
- 여러 페이지와 포털 연결을 프로젝트 JSON으로 함께 내보내고 가져옵니다.
- 학생은 초대 링크·별명·개인 PIN으로 접속해 에이전트와 제작 카드를 작성하고 그림을 첨부합니다. 허용된 교사가 승인한 버전만 이미지로 생성하며 학생이 보관함 저장 여부를 선택합니다.
- 바닥은 텍스처 한 장, 일반 소품은 같은 물체의 탑뷰·아이소 두 장을 생성합니다. 분류·태그로 검색하고 편집기 및 자연어 맵 에이전트에서 사용합니다.
- 학생은 기본 아바타의 옷·가방·신발 색을 무료로 바꾸고, 저장한 외형과 별명이 두 시점의 플레이에 적용됩니다.
- 교사 화면은 예상 출력 비용과 실제 사용량 기반 비용을 구분합니다. 키와 사용자 그림은 브라우저 번들이나 공개 Git에 넣지 않습니다.

- `app/`: React + Vinext 웹앱, Canvas2D 렌더러, 맵 편집·플레이·에이전트 API
- `design/assets/`: 직접 생성한 PNG 원본, 두 시점의 시트, 프레임 좌표, 생성 프롬프트
- `app/public/assets/atlas/`: 실행에 사용하는 압축 WebP와 프레임 JSON
- `design/ASSETS.md`, `design/DUAL_VIEW_V2.md`: 에셋 출처와 카메라·스타일 규격

## 로컬 실행

Node.js 22.13 이상을 사용합니다.

```sh
cd app
npm ci
npm run dev
```

에이전트 API를 쓰려면 `app/.env.example`을 참고해 `app/.dev.vars`에 서버 키와 `TEACHER_ALLOWLIST`를 설정합니다. 공방에는 D1 DB와 R2 파일 저장소 및 마이그레이션 적용이 필요합니다. 허용 교사 목록이 비어 있으면 교사 기능과 유료 생성이 열리지 않습니다. 세부 실행·DB·이식 절차는 [앱 README](app/README.md)와 [이식 안내](app/docs/PORTABILITY.md)에 있습니다.

## 기존 프로젝트로 가져가기

가장 먼저 전체 앱을 별도 경로 또는 서브도메인에서 실행해 연결할 수 있습니다. 화면을 직접 합치려면 기존 프로젝트의 프레임워크·로그인·서버 구조에 맞춰 라우트와 API를 통합해야 합니다. 포크만으로 다른 앱에 자동 삽입되지는 않습니다.

에셋만 가져가려면 `app/public/assets/atlas/`, 카탈로그(`app/lib/world/catalog.ts`), 프레임·렌더 규격을 함께 옮깁니다. 원본 수정과 재패킹까지 하려면 `design/assets/`와 `app/scripts/build-atlas.mjs`도 보존합니다. 이미지 파일만 옮기면 충돌 크기, 바닥 기준점, 방향·시점 정보는 자동으로 따라가지 않습니다.

현재 맵은 브라우저에 저장됩니다. 실제 사용자가 만든 맵은 편집기의 프로젝트 내보내기를 사용해야 하며 Git 포크에는 포함되지 않습니다. 프로젝트 JSON에는 페이지·포털 연결·사용한 에셋의 동작 정보가 들어갑니다. 학생의 생성 그림 파일 자체는 포함되지 않으므로 서버의 사용자·승인·에셋 데이터(D1)와 그림 파일(R2)도 별도로 이관해야 합니다. 이 데이터의 자동 일괄 내보내기는 아직 없습니다.

`app/.openai/hosting.json`의 `project_id`는 현재 운영 Site를 가리킵니다. 독립적으로 배포하는 포크에서는 해당 ID를 재사용하지 말고 새 호스팅 프로젝트를 연결해야 합니다. API 키와 호스팅 설정도 새 환경에 별도로 설정합니다.

## 에셋 출처

이 저장소의 모아 월드 그림은 이미지 생성 도구로 새로 제작한 에셋입니다. 브롤스타즈 APK에서 추출한 그림·캐릭터·로고는 런타임에 포함하지 않았습니다. 스타일과 데이터 구조를 분석한 참고용 APK 및 추출 분석 자료는 이 공개 저장소에 포함하지 않습니다. 제3자 라이브러리와 제공된 빌드 도구의 라이선스 고지는 원본 파일에 유지합니다.

학생 그림·생성 결과는 권한이 적용된 서버 저장소에 보관하며, 공개 Git 저장소에 자동 업로드하지 않습니다.

## 기준 버전

배포된 앱 소스 커밋: `924967d2d032abdc0e5dfb2b68cf8fbf91ffde16` (2026-10-20).
전체 테스트 79개, 타입 검사, 프로덕션 빌드를 통과했습니다. 독립 Chrome 세션에서 학생 가입·실제 대화·교사 승인·OpenAI 이미지 생성·보관함 저장·맵 배치와 아바타 적용을 확인했습니다. 새 빈 페이지에서 실제 GPT-6 Luna가 학생 보관함의 생성 바닥으로 요청한 6×6칸을 칠하는 흐름도 검증했습니다.

생성된 걷기 원본의 세부 포즈는 추가 개선 여지가 있습니다. 머리색 변경·AI 신규 걷기 아바타, 실시간 다중 사용자, 맵 서버 저장, 크롬북 실기 측정, 완전한 ZEP 기능 동등성은 아직 완료되지 않았습니다.

문이 열리는 다층 건물과 실내 진입 시 지붕 투명 효과는 후속 설계입니다. 현재 구현된 기능으로 표시하지 않습니다. 상세 범위는 `design/ASSET_WORKSHOP_V3.md`에 있습니다.
