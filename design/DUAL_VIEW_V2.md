# 모아 월드: 두 시점 아트 규격

2026-10-20 사용자 피드백에 따른 전면 교체. Codex가 이미지·디자인을, Claude가 앱 코드를 담당한다.

## 시점

- `td`: 북쪽을 향해 내려다보는 고정 직교 3/4 탑뷰. x축은 수평, y축은 수직. 사각 소품의 윗면과 남쪽 앞면을 보여 주며, 정면 방향에서 좌우 옆면이 나타나지 않는다. 바닥 64×48.
- `iso`: x축과 y축이 좌우 대각선으로 보이는 2:1 다이메트릭 게임 시점. 바닥 마름모 128×64. 소품의 윗면과 두 옆면을 보여 준다.
- 논리 좌표, 충돌, 에이전트 작업, 저장된 콘텐츠는 시점 전환과 무관하게 유지한다.
- 다른 시점의 스프라이트를 섞거나 단순 기울이기로 두 시점을 대체하지 않는다.

## 표현

- Brawl Stars에서 참고한 굵은 남색(`#1b1f3a`) 외곽선, 큰 실루엣, 선명한 색, 2–3단 셀 채색.
- 녹색·청록·코랄·금색·보라색 돌을 사용한다. 같은 물체는 시점이 달라도 색과 형태를 유지한다.
- 광원은 화면 왼쪽 위. 미세한 질감, 사진 같은 재질, 흐린 가장자리, 과도한 그라데이션은 제외한다.
- 투명 PNG 원본에서 WebP 아틀라스를 만든다. 드롭 섀도는 원본에 넣지 않고 렌더러에서 통일한다.
- 원본은 `assets/v2/`, 앱용 압축본은 `app/public/assets/atlas/`에 둔다.

## 구성

각 시점에 소품 시트 3장(4열×3행), 캐릭터 1장(4열×4행).
기존 카탈로그는 바닥 9종, 소품 27종이다. 방향 대안 9장을 더해 소품은 시점별 36프레임이다.

| 시트 | 행 우선 순서 |
|---|---|
| nature | tree, pine, bush, rock / flower, mushroom, crate, barrel / flag, lamp, fountain, flowerpot |
| furniture | desk, chair@a, chair@b, blackboard@a / blackboard@b, bookshelf@a, bookshelf@b, table / bench@a, bench@b, sign@a, sign@b |
| building | stone, wood, brick, stone_seg@a / stone_seg@b, fence@a, fence@b, house@a / house@b, quiz@a, quiz@b, portal |
| avatar | 정면/서쪽/뒷면/동쪽(td), 남동/남서/북서/북동(iso); 각 행 대기·걷기 A·중간·걷기 B |

`a`는 기존 기본 방향, `b`는 90도 방향이다. 자연물은 회전해도 광원이 뒤집히지 않게 한다. 비대칭 가구의 반전은 실제 뒷면 그림과 같지 않으므로 렌더러가 지원 범위를 명확히 처리한다.

## 바닥

바닥은 기존 코드로 그리는 자산을 개선한다. PNG 이음새와 확대 흐림 없이 두 시점에서 정확히 맞물리게 한다.

- 잔디: 선명한 연두/초록 면과 드문 큰 풀잎 표시. 촘촘한 점무늬를 줄인다.
- 흙·모래: 황토/밝은 금색 면, 작은 색 변화만 둔다.
- 돌: 청회색 큰 판석. 한 칸 안의 작은 벽돌 격자를 없앤다.
- 나무: 황금빛 넓은 판자와 짙은 접합선.
- 카펫·코랄: 선명한 면과 가장자리의 얇은 색 차이.
- 물: 청록/파랑 면, 드문 굵고 단순한 물결.
- 모든 바닥 칸에 검은 외곽선을 넣지 않는다. 두꺼운 선은 소품 및 지도 바깥 경계에 집중한다.

## 검증

두 시점 각각 에셋 패널, 편집 배치, 선택, 회전, 격자, 캐릭터 이동, 가림, 카메라, 저장·다시 열기를 확인한다. 모드 전환 전후 맵 콘텐츠가 같아야 한다. 선택하지 않은 시점의 비트맵 캐시를 유지하지 않으며 기존 저전력 예산을 지킨다.

실제 크롬북의 성능은 실기에서 따로 측정해야 한다. Mac Chrome 측정치는 회귀 비교에만 사용한다.
